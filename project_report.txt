Name: Banker's Algorithm Safety Analyzer

## 1. Introduction
This report details a Python-based desktop application designed to simulate and analyze two fundamental operating system algorithms: the Banker's Algorithm for deadlock avoidance and a standard Deadlock Detection Algorithm. The application provides a user-friendly graphical interface (GUI) to run simulations, visualize results, and understand the statistical differences in outcomes between these two mechanisms. It serves as a practical tool for studying resource allocation strategies and their impact on system stability.

## 2. Project Objectives
The primary goals of this project were:
- To implement the Banker's Algorithm to determine if a system state is safe.
- To implement a Deadlock Detection Algorithm to identify existing deadlocks.
- To build an intuitive GUI for users to configure and run simulations.
- To use simulation to generate random system states (processes, resources, allocations) and test them.
- To present the simulation results in a clear, understandable format, using both tables and graphs.
- To compare the probabilities of safe outcomes from both algorithms under various loads.

## 3. Technologies Used
- **Python 3**: The core language for the application logic.
- **Tkinter**: Python's standard library for creating the graphical user interface.
- **NumPy**: Used for its powerful N-dimensional array objects, which are ideal for handling the matrices required by the algorithms (Max, Allocation, Need).
- **Pandas**: Employed to organize the simulation results into a structured DataFrame, which is then displayed in a tabular format.
- **Matplotlib**: The library of choice for plotting the data, providing visual insights into the simulation outcomes.

## 4. Core Algorithms

### 4.1. Banker's Algorithm
This algorithm is a deadlock avoidance strategy. It checks whether granting a resource request will lead to an unsafe state. An unsafe state does not guarantee a deadlock but indicates that the system cannot guarantee that all processes will be able to finish. Our implementation simulates this by generating a random system snapshot and determining if there's a sequence in which all processes can run to completion.

### 4.2. Deadlock Detection Algorithm
This algorithm is used to find out if a deadlock already exists in the system. It works with the current allocations and pending requests to see if there is a circular wait condition where one or more processes are blocked indefinitely. Our implementation checks if any processes can complete their work; if not all can, a deadlock is presumed to exist among the remaining processes.

## 5. Application Features and GUI
The application interface is designed for simplicity and ease of use:
- **Inputs**: Users can specify the maximum number of processes to simulate and the number of trials for each process count.
- **Simulation Control**: A "Run Simulation" button initiates the analysis.
- **Results Table**: A text area displays the results generated by Pandas, showing the percentage of "safe" states found by each algorithm for each process count.
- **Graphical Plots**:
    1.  **Safety Probability vs. Processes**: A line plot that visualizes how the likelihood of a safe state changes as the number of processes grows. This directly compares the outcomes of the Banker's Algorithm and the Deadlock Detection simulation.
    2.  **Safe vs. Unsafe Distribution**: A bar chart that gives an aggregate view of all simulations run, showing the total number of safe and unsafe states encountered.
- **Sample Matrices Viewer**: A feature that allows the user to see the exact `Max`, `Allocation`, and `Available` matrices for one of the random test cases, which is useful for educational purposes.

## 6. How to Use the Application
1.  Run the `Bankers.py` script using a Python 3 interpreter.
2.  In the main window, enter the desired number for "Maximum Number of Processes" and "Test Cases per Process Count."
3.  Click "Run Simulation."
4.  Two Matplotlib windows will appear with the graphs, and the main GUI window will show the detailed tabular results.

## 7. Conclusion
This project successfully implements the Banker's and Deadlock Detection algorithms in a visual and interactive manner. The simulation results demonstrate the dynamics of resource allocation and system safety. By visualizing the probability of safe states, the application provides a clear educational tool for understanding why deadlock avoidance mechanisms like the Banker's Algorithm are crucial for designing stable operating systems. It effectively bridges the gap between theoretical concepts and practical, observable outcomes.
